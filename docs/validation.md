# 实测与公开验证范围

## 原设备实测

- 设备：Surface Pro 8，Ubuntu 24.04，GNOME Wayland，linux-surface 内核。
- Linux 电源键记录：物理短按后显示 `PowerSaveMode=3`；锁定提示为真；网络 connected，SSH 检查继续运行，未出现对应 suspend 事件。
- 上述物理网络记录使用 `7.2.12-1-surface`；后续设备已更新到 `7.2.13-1-surface`，不能把旧日志改写成新内核的独立测试。
- 后续背光恢复和唤醒有单独维护信号测试；它验证相同显示动作，不证明新的物理按键循环。
- GRUB 音量选择与电源确认已由使用者确认成功。2026-11-02 最新反馈为“启动仍卡一下，其他验收没有问题”。
- 图形工具箱已由使用者验收；其功能与三键菜单分开记录。

具体源代码哈希和已验收 EFI 哈希见 [validation.json](validation.json)。该 EFI 是原设备的验收标识，公共仓库提供源代码供本地重建，并未分发原设备签名镜像。

## 公开构建与检查

`tools/check.py` 检查源归档、Python 语法、安装器备份和恢复、安装后另改文件的保护、GRUB 版本哈希和路径越界拒绝；测试使用临时目录，没有读取 `/dev/input`、MMIO 或修改桌面。

`prepare-source.py` 应用固定 Ubuntu 和 Surface 补丁并覆盖新增源文件。源码编译与宿主模拟仅说明软件路径通过，不替代目标 Surface 的固件、签名和按键实测。

## 保留的问题

启动短暂停顿仍在原设备最新反馈中。原窗口已继续处理固件输入轮询；这一正在修订的版本没有混入首次公开基线。后续合并需要明确版本和新证据。

其他 Surface、其他二合一设备、ROG 幻 X 2023，以及其他桌面环境均没有本项目实测通过结论。


## 首次公开版本的软件检查结果

- 7 项 Python/安装/恢复/锁定与原始事件处理检查通过。
- 186 个固定 Ubuntu 补丁和 Surface 核心补丁均可应用。
- x86_64 EFI 完整 configure/make 通过，GNU awk 为必要依赖。
- 独立未签名 EFI 生成通过：6,213,632 字节。为避免接触现役引导，验证使用占位 UUID，仅作构建检查。
- 公开源码的 EFI console 与 GOP damage 宿主 fixture 运行通过；本地 ARM 宿主编译出现接口类型兼容警告，完整 x86_64 构建仍通过。
- 未把公共构建签名、部署或启动，也没有把软件检查当作新的实机验收。
